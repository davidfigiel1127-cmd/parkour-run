# Parkour Run

An endless rooftop runner that plays in the browser on desktop and phone. No build step and no dependencies.

**Play:** open `index.html` in a browser (or turn on GitHub Pages for this repo).

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Jump | Space / ↑ / W | Tap the right side |
| Double jump | Jump again in the air | Tap again in the air |
| Slide | ↓ / S (hold) | Hold the left side |
| Drop fast | ↓ / S in the air | Hold the left side in the air |
| Pause | P / Esc | Pause button |
| Mute | M | Speaker button |

Hold jump longer to jump higher.

## Features

- Endless, randomly built rooftops that get faster and harder as you go
- Barriers and crates to jump, billboards to slide under, gaps to clear
- Coins, style points for close calls and slides, and a saved best score
- Sky that cycles from sunset to night to dawn to day
- Parallax city skyline, particles, screen shake and sound effects
- Forgiving controls: jump buffering and a short grace period after leaving a ledge
- Auto-pauses when you switch tabs
